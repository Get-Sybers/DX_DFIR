# Documentation images

Screenshots and diagrams referenced by the docs live here.

The [interface guide](../getting-started/the-interface.md) shows `dx` output as
**faithful terminal renderings in fenced code blocks**: they render in any Markdown
viewer and never go stale against a redraw. To use real captures instead, run `dx` on a
terminal, screenshot the output, drop the PNGs in this folder (e.g. `pipeline.png`), and
reference them from the interface guide with a standard Markdown image link.

> Keep captures small and cropped to the terminal. Don't commit anything containing real
> evidence.
