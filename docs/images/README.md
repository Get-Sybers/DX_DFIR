# Documentation images

Screenshots and diagrams referenced by the docs live here.

The [interface guide](../getting-started/the-interface.md) currently shows the `dxdfir`
UI as **faithful terminal renderings in fenced code blocks** — they render in any Markdown
viewer and never go stale against a redraw. To use real captures instead, run `dxdfir` on
a terminal, screenshot each tab, drop the PNGs in this folder (e.g. `pipeline.png`), and
reference them from the interface guide with a standard Markdown image link.

> Keep captures small and cropped to the terminal. Don't commit anything containing real
> evidence.
